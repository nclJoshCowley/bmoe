# Simulate Design Matrix

A design matrix of chosen width is simulated for use in studies.

## Usage

``` r
simulate_x(n_s, n_x, .scale = TRUE)
```

## Arguments

- n_s:

  integer. Number of observations (rows).

- n_x:

  integer. Number of explanatory variables (columns).

- .scale:

  logical. When `TRUE`, output is scaled before returned.
